# Профиль владельца

> Этот файл заполняется в ходе онбординга. До его завершения — шаблон.

## Базовое

- **Язык общения:** русский (если явно не попросили иначе).
- **Стиль ответов:** прямые и конкретные, без лишних слов.

## Статус онбординга

Онбординг не проведён. После знакомства здесь появятся:
- Роль и сфера деятельности владельца
- Ключевые задачи и рабочие сценарии
- Инструменты, сервисы, репозитории
- Предпочтения в стиле работы

## Приоритеты агента (заданы при развёртывании)

- Экономия токенов: L4 Cognee вызывать только при необходимости.
- Автоматическое запоминание важных фактов между сессиями без лишних вопросов.
- Прямые, лаконичные ответы.
